# Tribal Saarthi - MoTA Scholarship & Fellowship System Prototype

Welcome to the Tribal Saarthi Prototype repository. This project is developed for the Smart India Hackathon (SIH) for the Problem Statement PS-26239: MoTA Scholarship & Fellowship System.

## Overview
Tribal Saarthi is a unified, scalable, and intelligent platform designed to streamline the application, verification, and disbursement processes for the Ministry of Tribal Affairs (MoTA) scholarships and fellowships.

### Key Features
- **Integrated Application Portal:** Seamless application experience for Pre-Matric, Post-Matric, and Fellowship schemes.
- **AI-Assisted Verification:** OCR and document intelligence to aid verifying officers.
- **Data Privacy & Security:** Compliant with DPDP Act 2023. Aadhaar data is tokenised/masked.
- **Integration Ready:** Adapter-pattern architecture for integration with existing systems (NSP, DigiLocker, PFMS).
- **Multilingual Support:** Accessible in multiple regional languages (WCAG 2.1 AA compliant).

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend (Proposed):** Python FastAPI, PostgreSQL (JSONB)
- **Integrations:** REST APIs

## Setup & Running Locally
1. Clone the repository.
2. Open `index.html` in your browser.
3. No build tools are required for this frontend prototype.

## Disclaimer
All data, IDs, and tokens in this prototype are synthetic/demo data and do not represent real individuals.
